# Core role clarity audit

Reviewed 19 October 2026. Scope: all 60 base roles and four transformed states in the vanilla text-chat, normal-faction baseline.

The starting gap was Hex Master: the guide mentioned a Hex Bomb without telling a beginner how to cause it. The same audit checks every role for its action, payoff prerequisite, actual win and a small worked example.

## Before and after

| Before | After | Benefit |
| --- | --- | --- |
| Abstract role description before detailed strategy | A compact Do / Key rule / Win block on the main role header and at the top of Role guide | The ability and victory requirements are visible without opening More detail |
| Hex Bomb “requires the Hex Master to remain active under its conditions” | Every living non-Coven player must be Hexed; survive to resolution; automatic activation; no separate button or book required | A beginner can tell what still needs to happen |
| Transformations mentioned without a checklist at the top | Baker: three other living Bread recipients; Berserker: actual kill thresholds; Plaguebearer: all other living players infected; Soul Collector: seven souls | Selection, progress, transformation and winning stay distinct |
| Generic faction win repeated for personal-objective roles | Hanging plus quota for Jester; assigned target hanged while alive for Executioner; all three assigned Landlubbers dead while alive for Pirate; one complete correct set for Doomsayer | An ordinary death or partial progress is not mistaken for a win |
| Six leaked wiki color fragments in ability labels | Clean Necronomicon, Phantasm and Disguise names | The ability table is readable |
| Jester example continued after missing quota | The illustrated surviving day completes quota; note explains boredom death and failed win | The example no longer models an impossible continuation |

## Sources and boundaries

Core content is authored in `site/content/role-essentials.json`. Each entry links the prior reviewed role pages and lists installed role-card/faction keys. [Primary evidence](../research/CORE_MECHANICS_EVIDENCE.json) retains 189 English-entry fingerprints from R1.5.14, Steam build 24079984. The read-only verifier rechecks these against the game bundle. No complete localization table or game asset is distributed.

These are original plain-English summaries rather than literal game messages. Presence of a shipped role card does not prove every live server interaction; previous conflict notes remain in the deeper sources. Hex day-transition timing, dead-Hex-Master reanimation and defense bypass stay in Interactions and limits, while the normal activation rule stays visible. Conversion and Flexible Factions can alter the applicable faction goal.

The normal Town and Coven win descriptions explicitly permit sharing a team victory after death; roles needing personal survival state that condition. Non-Town role objectives are never substituted for a selected Town cover. Blank will/player-note formatting is preserved.
