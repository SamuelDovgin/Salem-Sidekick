# Beginner glossary and clear communication

These explanations apply to the default vanilla text-chat profile. They are original concise definitions; role-specific exceptions remain in the [mechanics chapter](../research/MECHANICS.md). Sources: [alignments](https://townofsalem.wiki.gg/wiki/Alignment_(ToS2)), [keywords](https://townofsalem.wiki.gg/wiki/Keywords_(ToS2)), [attributes](https://townofsalem.wiki.gg/wiki/Attributes_(ToS2)).

| Term | Plain-language meaning |
| --- | --- |
| Role | Your ability set; it can differ from your current faction |
| Faction | The team/win objective you currently belong to |
| Alignment / subalignment | A role family such as Town Protective; chat often calls this alignment |
| Claim | What you tell others your role or category is |
| Full claim | Naming your exact role, usually with the relevant action history |
| Fake claim / cover | A role story different from your actual role |
| Will | A concise record of claimed role, actions, and results |
| N1 / N2 | Night 1 / Night 2; label the night the action occurred |
| D2 / D3 | Day 2 / Day 3; important for day abilities |
| TI | Town Investigative: information-gathering roles |
| TP | Town Protective: roles that protect in distinct ways |
| TK | Town Killing: lethal or attack-handling Town roles; do not abbreviate Tavern Keeper this way in this app |
| TS | Town Support: support abilities that do not fit the other families |
| TPow | Town Power: unique high-impact roles; it is different from TP |
| CPOW / CK / CD / CU | Coven Power / Killing / Deception / Utility |
| NE / NK / NA | Neutral Evil / Neutral Killing / Neutral Apocalypse |
| Outlier | Setup-dependent role that normally needs explicit availability or a suitable modifier |
| VFA | Vote for Alignment: pressure players to state a role category |
| VFR | Vote for Role: pressure players to state an exact role; not identical to VFA |
| TP/LO | A request for protection and Lookout attention; do not blindly send dangerous visitor-attacking roles |
| CC | Counterclaim: a claim competing with another claim for credibility or constrained role space |
| Claim space | The set of role possibilities still compatible with the setup and reliable evidence |
| Unique | Normally at most one instance of that role in the role list; transitions/effects need context |
| 1-for-1 / 1f1 | A claimed conflict where at least one side is wrong under stated assumptions; it does not automatically identify the liar |
| RB | Roleblock: interruption of an eligible ability |
| UO | Unknown Obstacle: destination-related failure, not necessarily a roleblock |
| Astral | Does not behave as an ordinary visit for many observers and visitor hazards |
| Direct visit | A normal visit to a selected destination; visibility is separate from whether it is harmful |
| Harmful visit | An attacking action relevant to specific interception mechanics |
| NV | Often “no visit”; this app prefers “No visible visit” to avoid implying no action |
| Inno / Sus | Innocent / Suspicious appearance to a check; neither is an exact role |
| Barrier / Defense | Protection properties; sufficient defense depends on the attack and special mechanics |
| Rampage | An attack effect that can also strike visitors at the chosen house |
| Book | Necronomicon: changes Coven killing and some role behavior |
| Confirmed | An overloaded chat term: specify whether an ability was demonstrated, a result was observed, or faction was established under current assumptions |
| Push | Present a case and encourage action against a player |
| Flip | A revealed role/faction after death; hidden or altered deaths need caution |
| Majority / parity | Voting-control concepts; count actual weighted votes rather than only living bodies |

## Message structure the beginner cards should teach

Use **observation → limited meaning → useful question**.

- “Sheriff, N1 #4 Innocent. This does not clear them. What are they claiming?”
- “Tracker, N2 #7 -> #9. #7 says they went to #4; was there redirection?”
- “Investigator, N2 #7 Trespassing. Who have they visited? The result alone does not prove evil.”

These are invented examples for learning phrasing, not live results or a recommendation to fabricate Town information. Real players should report the feedback they actually received; an evil maintaining a cover needs to understand the same logical limitations.
